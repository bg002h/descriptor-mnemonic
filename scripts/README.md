| script | path | purpose | usage |
| --- | --- | --- | --- |
| `code-docs-check.sh` | `ci/code-docs-check.sh` | Fails if any scanned code file names a file that ci/docs-only.sh treats as documentation (which would let a docs-only change skip the job that reads it). | `bash ci/code-docs-check.sh` |
| `code-docs-check.test.sh` | `ci/code-docs-check.test.sh` | Scenario tests for code-docs-check.sh, one throwaway git repo per row; needs only git and bash. | `bash ci/code-docs-check.test.sh` |
| `docs-only.sh` | `ci/docs-only.sh` | CI guard: writes docs_only=true to $GITHUB_OUTPUT only when every file changed since the reference commit is documentation per ci/docs-only-paths.txt; any doubt writes false. Reads event shape from CI env (PR_BASE_SHA, PUSH_BEFORE, DEFAULT_BRANCH, CHECK_NAME). | `bash ci/docs-only.sh` |
| `docs-only.test.sh` | `ci/docs-only.test.sh` | Scenario tests for docs-only.sh against a scratch file:// origin and a stand-in gh; never touches the real remote. | `bash ci/docs-only.test.sh` |
| `vendor-freshness.sh` | `ci/repro/vendor-freshness.sh` | Four-check vendor/ gate (shared file): resolution under an empty CARGO_HOME, file integrity, registry provenance, and each git source re-derived from upstream at its Cargo.lock rev (rows in ci/repro/vendor-git-sources.txt). | `bash ci/repro/vendor-freshness.sh` |
| `vendor-freshness.test.sh` | `ci/repro/vendor-freshness.test.sh` | Mutation tests for vendor-freshness.sh (shared file; needs python3, tar, git, cargo and network). | `bash ci/repro/vendor-freshness.test.sh` |
| `gen-compose-golden.sh` | `scripts/gen-compose-golden.sh` | Regenerates crates/md-cli/tests/golden/compose_pre_unspendable.json from a PRE-`--unspendable` md binary over presets x wrappers; refuses a binary that knows --unspendable. Env MD sets the binary (default target/debug/md). | `MD=/path/to/pre-flag/md scripts/gen-compose-golden.sh` |
| `matrix-identity-check.sh` | `scripts/matrix-identity-check.sh` | Extracts the six-line 'in \ out' matrix table from its four homes (brainstorm, spec, plan, code comment) and requires byte-identical copies; exit 0 = identical. | `scripts/matrix-identity-check.sh` |
| `phase-gate.sh` | `scripts/phase-gate.sh` | The mdcli-mini phase gate as a command: nextest, doctests, clippy -D warnings, fmt --check and cargo doc -D warnings, all-features; exit 0 = every step passed (CI-only legs not covered). | `scripts/phase-gate.sh` |
| `push-via-staging.sh` | `scripts/push-via-staging.sh` | Repo-agnostic ci/staging push ritual: pushes the branch to ci/staging, waits for the required contexts (from branch protection) or all workflow runs, stops on any failure, then pushes the checked tip. | `scripts/push-via-staging.sh [branch]` |
| `vendor-coord-evidence.sh` | `scripts/vendor-coord-evidence.sh` | Vendors coordinator-compatibility evidence from a mnemonic-engrave checkout into md-codec's coordinator fixtures (evidence.jsonl + evidence.meta.json); --check fails if the committed copy is stale. | `scripts/vendor-coord-evidence.sh [--check] <path-to-mnemonic-engrave>` |
| `vendor-liana-evidence.sh` | `scripts/vendor-liana-evidence.sh` | Extracts the Liana unspendable-xpub records from mnemonic-engrave's composer-fable-r0 evidence JSONL into md-codec's liana/cases.json fixture. | `scripts/vendor-liana-evidence.sh <path-to-mnemonic-engrave>` |
| `generate.sh (decompose)` | `crates/md-cli/tests/fixtures/decompose/generate.sh` | Regenerates the V-D-RT fixture v-d-rt.txt by running the mint routes that `md decompose --emit commands` prints, with md from this repo and mk from mnemonic-key (env MD, MK). | `MK=/path/to/mk crates/md-cli/tests/fixtures/decompose/generate.sh` |
| `generate.sh (seating)` | `crates/md-cli/tests/fixtures/seating/generate.sh` | Regenerates every synthetic seating fixture in its directory using md (this repo) and mk (mnemonic-key), both resolved by path (env MD, MK). | `MK=/path/to/mk crates/md-cli/tests/fixtures/seating/generate.sh` |
| `extract-keyed-card.sh` | `crates/md-cli/tests/fixtures/pathological/extract-keyed-card.sh` | Re-extracts keyed-card.txt (the 22-string keyed md1 card) from the rendered pathological journey page, asserting the token shape before writing (env SRC). | `SRC=/path/to/journey_pathological.html crates/md-cli/tests/fixtures/pathological/extract-keyed-card.sh` |
| `derive.py` | `crates/md-codec/tests/fixtures/network/derive.py` | Derives the F-672 non-mainnet golden descriptors from a mainnet descriptor on stdin by swapping xpub version bytes to testnet and recomputing the BIP-380 checksum. | `python3 crates/md-codec/tests/fixtures/network/derive.py < mainnet-descriptor` |
| `gen_ap2_grind` | `crates/md-cli/src/bin/gen_ap2_grind.rs` | Deterministic ~2^32 grind that emits the AP2 seat-auto-partition fixture v-ap2.txt (a genuinely ambiguous mk1 chunk-set cover) to stdout. | `cargo run -p md-cli --bin gen_ap2_grind --release > crates/md-cli/tests/fixtures/seating/v-ap2.txt` |
| `xtask` | `crates/xtask/src/main.rs` | `cargo xtask verdicts` builds md-codec's coordinator verdict table (coordinator/table.rs) from the vendored evidence.jsonl; --check writes nothing and exits 1 if the table is stale. | `cargo xtask verdicts [--check]` |
