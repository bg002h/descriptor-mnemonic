## Critical

### C1 · Concrete descriptor conversion moves post-key derivation into the origin

`md decompose` builds the placeholder by concatenating the origin and use-site strings at `crates/md-cli/src/decompose/walk.rs:357`. The template reader treats the resulting numeric components as origin metadata at `crates/md-cli/src/parse/template.rs:245`. It also collapses an absent wildcard into the unhardened wildcard at line 345. A concrete descriptor distinguishes all three pieces. The user can lose the wallet's receive branch when converting it to a backup.

```sh
md decompose "wpkh([73c5da0a/48'/0'/0'/2']${X}/0/*)" --emit commands
md encode "wpkh(@0/48'/0'/0'/2'/0/*)" --key "@0=$X" --fingerprint @0=73c5da0a > "$D/fixed.md1"
mapfile -t cards < "$D/fixed.md1"
md address "${cards[@]}"
```

The second command is route 1 printed by the first, with equivalent shell quoting. All three exited 0. An isolated Bitcoin Core **27.0** `getdescriptorinfo` → `deriveaddresses` on the original at index 0 returned **`bc1qtncy45g8qy8laah6jvxn6ppvj0s9rluxj5uxf6`**. The backup returned **`bc1q8qydrp3penwz2aaurncw6qfa85ef7ywn047wqw`**, the address for `X/*` at index 0. The mint printed the existing F-411 depth advisory and still emitted all chunks. Decompose emitted no warning. Removing the entire suffix from the concrete descriptor also minted the same wallet as explicit `/*`, with no excess-depth clue. A concrete `/<0;1>/*` control preserved the correct first address.

**Fix and regression.** Validate the parsed `DescriptorPublicKey` derivation paths and wildcard before emitting an md template or either mint recipe. Preserve the original concrete descriptor for exact export. Refuse the conversion when md1 cannot express the source use-site. The representation boundary and refusal rule are explicit in `crates/md-codec/src/use_site_path.rs:13`. Add separate rows for `/0/*`, `/7/*`, no suffix, and `/7/<0;1>/*`. Require an actionable refusal and empty artifact output. For representable `/*` and `/<0;1>/*`, run the emitted route and compare addresses for the same chain and index against Core. Keep the direct md-template origin grammar intact.

### C2 · Renumbering placeholders puts an override on the reserved baseline slot

```sh

md decode md1yppqqxppsg2qk3q2zc2pz7ecekxclml
```

**Fix and regression.** At `crates/md-codec/src/canonicalize.rs:249`, `canonicalize_placeholder_indices` remaps sparse use-site indices but keeps the old baseline. Run the canonical-override validator before mint. Assert that these two spellings produce identical payload bytes **and bit counts**, identical cards, and readable single and forced-chunked output. Add distinct keys per slot in a second row and compare both chains after renumbering.

### C3 · Two different keys for one slot select a wallet by argument order

```sh

md address --template "$T" --key "@0=$Y" --key "@0=$X"
```

Both exited 0. The first returned the X-only control, `bc1qtncy45g8qy8laah6jvxn6ppvj0s9rluxj5uxf6`. The second returned the Y-only control, `bc1q497wxg3wrtsallkdcmnksecr8entsvz66uh4ee`. `md descriptor` selected the corresponding different xpubs too. Keep both single-key controls and a two-slot wallet with one key per slot.

### C4 · A failed file replacement destroys the previous backup

`md encode --out` calls `crates/md-cli/src/cmd/mod.rs:109`. The shared writer opens the live path with `truncate(true)` before `write_all` at `vendor/mnemonic-io-lib/src/write.rs:49`. The keyed `md descriptor --emit md1 --out` route reaches the same writer at `crates/md-cli/src/cmd/descriptor.rs:456`.

```sh

python3 - "$D/prior.md1" <<'PY'

p = pathlib.Path(sys.argv[1])
before = p.read_bytes()
def short_write():
    resource.setrlimit(resource.RLIMIT_FSIZE, (8, 8))
    signal.signal(signal.SIGXFSZ, signal.SIG_IGN)
r = subprocess.run(["md", "encode", "pkh(@0/<0;1>/*)", "--out", str(p)],
```

Observed `2 25 b'md1yqpqq'` and a named `File too large` error. The previous 25-byte file decoded successfully before the attempted replacement. The keyed descriptor route also exited 2 and reduced a valid 345-byte backup to eight bytes.

Clean up on failure. Preserve the documented overwrite policy, 0600 mode, and intended stream semantics. Fix the source helper upstream and repin, or provide the replacement semantics in the local caller. Exercise an existing valid file, short write, byte-identical preservation, and successful retry through both CLI routes.
